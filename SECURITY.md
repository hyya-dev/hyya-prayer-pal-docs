# Security

## Report a security problem privately

If you find a security problem in hYYa Prayer Pal, please tell us **privately**: in the app, **Settings → Report a Security Issue** opens a new e-mail to our security team, or use the form at [hyya.com/contact.html](https://hyya.com/contact.html).

**Please don't open a public issue for it.** Issues here are public the moment they are filed.

Tell us, if you can:
- the device and system (for example: iPhone with iOS 26, Android 15),
- the app version, shown on the app's page in the App Store or Google Play,
- what you did and what happened.

## What happens next

We read every report, reproduce the problem, fix it in an update for each platform it affects, and tell you when the fix is out.

## Which versions get fixes

Fixes ship as updates through the App Store and Google Play. Keep automatic updates on.

## Security advisories

None so far.
